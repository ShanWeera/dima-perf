Download the latest DiMA GUI release from [GitHub Releases](https://github.com/ShanWeera/dima-perf/releases).

## Download

DiMA GUI is distributed as a single binary — no installer required.

<Tabs syncKey="os">
  <TabItem label="macOS">
    Download the `.tar.gz` archive for your architecture:

    - **Apple Silicon (M1/M2/M3/M4):** `dima-gui-*-aarch64-apple-darwin.tar.gz`
    - **Intel (x86_64):** `dima-gui-*-x86_64-apple-darwin.tar.gz`

    ```bash
    tar -xzf dima-gui-*.tar.gz
    ./dima-gui-*/dima-gui
    ```

    On first launch, macOS may show a Gatekeeper warning. Right-click the binary → Open to bypass.
  </TabItem>
  <TabItem label="Linux">
    Download the `.tar.gz` archive:

    - **x86_64:** `dima-gui-*-x86_64-unknown-linux-gnu.tar.gz`

    ```bash
    tar -xzf dima-gui-*.tar.gz
    chmod +x dima-gui-*/dima-gui
    ./dima-gui-*/dima-gui
    ```
  </TabItem>
  <TabItem label="Windows">
    Download the `.zip` archive:

    - **x86_64:** `dima-gui-*-x86_64-pc-windows-msvc.zip`

    Extract the archive and run `dima-gui.exe`.
  </TabItem>
</Tabs>

## Build from Source

```bash
cargo install --git https://github.com/ShanWeera/dima-perf -p dima-gui
```

<Aside type="note">
Building from source on Linux requires system libraries for egui/wgpu:
`libxkbcommon-dev`, `libwayland-dev`, `libxcb-render0-dev`, `libxcb-shape0-dev`,
`libxcb-xfixes0-dev`, `libxrandr-dev`, `libxi-dev`, `libxtst-dev`, `libx11-dev`,
`libgl-dev`, `libegl-dev`, `libvulkan-dev`.
</Aside>

## System Requirements

| Requirement | Minimum |
|-------------|---------|
| OS | macOS 11+, Windows 10+, Linux (glibc 2.31+) |
| GPU | Vulkan, Metal, or DX12 capable (integrated graphics sufficient) |
| RAM | 4 GB (8 GB recommended for large datasets) |
| Disk | ~15 MB for binary |
| Display | 1280×720 minimum |
