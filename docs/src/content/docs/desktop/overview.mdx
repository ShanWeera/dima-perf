DiMA GUI is a native desktop application for interactive sequence diversity analysis, built with [egui](https://github.com/emilk/egui) and rendered via [wgpu](https://wgpu.rs/).

## Architecture

DiMA GUI is a single compiled binary with no WebView, no JavaScript, and no runtime dependencies:

- **egui / eframe** — Immediate-mode GUI framework providing the entire user interface
- **wgpu** — GPU-accelerated rendering backend (Vulkan, Metal, DX12)
- **dima_lib** — The same Rust library used by the CLI, linked directly with zero-copy data access

This architecture ensures the desktop app produces **identical results** to the CLI — the same entropy calculations, motif classification, and HCS extraction.

## Key Differences from CLI

| Feature | CLI | Desktop |
|---------|-----|---------|
| Interface | Terminal commands | Graphical UI |
| Interaction | Batch processing | Interactive exploration |
| Input | File paths, stdin | File dialog / drag-and-drop |
| Output | Files, stdout | Visual charts + export |
| Automation | Scriptable | Manual workflow |

<Aside type="note">
The desktop app is ideal for exploring individual datasets interactively, while the CLI excels at batch processing, automation, and integration into pipelines.
</Aside>

## Status

DiMA GUI is in active development. Pre-built binaries are available for all major platforms in the [GitHub Releases](https://github.com/ShanWeera/dima-perf/releases).
